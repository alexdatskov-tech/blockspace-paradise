BlockForge is proprietary. Everything in [LICENSE](LICENSE) is reserved, and
**no** use, copying, hosting, modification or redistribution is permitted
without the Owner's prior written consent.

To request permission, copy the form below, fill in **every** field, and send
it to the Owner. Incomplete requests are not considered.

**Send to:** open a [GitHub issue](https://github.com/alexdatskov-tech/blockspace-paradise/issues/new?labels=licence-request&title=Licence%20request)
using the `licence-request` label, or contact the Owner privately if the
request is confidential.

**Do not** copy, deploy or modify anything while a request is pending. A
request is not permission — only a written approval from the Owner is.

## What happens next

1. The Owner reviews the request. There is **no** guaranteed response time, and
   there is no obligation to grant permission or to give a reason for refusing.
2. If approved, you receive a written grant naming exactly who may use the
   Software, for what, where and for how long. That grant — not this form, and
   not the absence of a refusal — is your permission.
3. Anything outside the approved scope stays prohibited and terminates the
   grant automatically.

## Note on forking

This repository is public, so the GitHub Terms of Service let any GitHub user
fork it **within GitHub**. That platform right cannot be revoked by the licence
or by this form. It does **not** permit hosting, deploying, redistributing
outside GitHub, or any commercial use — those still require written consent.
